# WARP.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Project Overview

btrack is a Wails v2 application that combines a Go backend with a React frontend. Wails is a framework for building desktop applications using Go and web technologies, similar to Electron but with native Go bindings instead of Node.js.

## Architecture

### Backend (Go)
- **main.go**: Application entry point that configures and launches the Wails app
  - Embeds the compiled frontend assets from `frontend/dist`
  - Creates the App instance and binds it to the frontend
  - Configures window dimensions (1024x768) and styling
- **app.go**: Contains the main App struct and methods exposed to the frontend
  - Methods in this struct are automatically callable from JavaScript via Wails bindings
  - The `startup` method is called when the app starts and stores the runtime context

### Frontend (React + Vite)
- **Location**: `frontend/` directory
- **Framework**: React 18 with Vite as the build tool
- **Bindings**: The `frontend/wailsjs/` directory contains auto-generated TypeScript/JavaScript bindings
  - These bindings allow calling Go methods from the frontend (e.g., `Greet` function in `App.jsx`)
  - DO NOT manually edit files in `wailsjs/` - they are regenerated by Wails

### Build Artifacts
- **frontend/dist**: Compiled frontend assets (embedded into the Go binary)
- **build/**: Platform-specific build configurations and assets
  - `build/darwin/`: macOS-specific resources
  - `build/windows/`: Windows-specific resources
  - `build/appicon.png`: Application icon

## Key Commands

### Development
```bash
# Run in live development mode with hot reload
wails dev
```
This starts both the Go backend and Vite dev server. The frontend will be available at the dev server URL with hot reload enabled. Go methods are accessible at http://localhost:34115 for browser-based development.

### Building
```bash
# Build production binary for current platform
wails build
```
This compiles the frontend, embeds it into the Go binary, and creates a distributable application.

### Frontend Only
```bash
# Install frontend dependencies
cd frontend && npm install

# Run frontend dev server independently (without Go backend)
cd frontend && npm run dev

# Build frontend assets
cd frontend && npm run build
```

## Development Workflow

### Adding New Go Methods
1. Add public methods to the `App` struct in `app.go`
2. Methods must be exported (capitalized) to be accessible from frontend
3. Run `wails dev` - the bindings in `frontend/wailsjs/` will be auto-regenerated
4. Import and use the new method from `frontend/wailsjs/go/main/App` in React components

### Modifying the Frontend
- Edit React components in `frontend/src/`
- Changes will hot reload automatically when running `wails dev`
- Use the generated bindings from `wailsjs/` to call Go backend methods

### Configuration
- **wails.json**: Project configuration including build commands and metadata
- **frontend/vite.config.js**: Vite configuration for the React frontend
- **go.mod**: Go dependencies

## Important Notes

- The Wails bindings in `frontend/wailsjs/` are auto-generated - never edit these files manually
- Frontend assets are embedded into the Go binary at build time via the `//go:embed` directive in `main.go`
- When adding new Go methods, they must be public (capitalized) and bound in `main.go` to be accessible from the frontend
- The app uses Go 1.23 and Wails v2.11.0
